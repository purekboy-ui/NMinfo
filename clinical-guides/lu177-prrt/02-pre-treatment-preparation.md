# Lu-177 PRRT：治療前準備

## 治療前一定要完成的評估

### 病況本體評估

- 病理確認為 **well-differentiated NET**。（2026 指引，第7頁）
- 評估 **體能狀態**：Karnofsky/Lansky >60% 或 ECOG ≤2 為較常見門檻。（2026 指引，第7頁）
- 確認疾病範圍與可治療性：是否為 **轉移性或不可切除** 病灶。（2026 指引，第6-7頁）

### 影像評估

- **SST PET/CT** 為首選，用來確認所有主要病灶是否具足夠受體表現。（2026 指引，第7頁）
- 如屬 G2/G3、G1 但進展異常快，或 CT / MRI 與 SST PET 不一致，應追加 **FDG PET/CT** 做 aggressiveness / mismatch 分層。（2026 指引，第7頁）

### 實驗室與臨床風險評估

- 血球、腎功能、肝功能需先建立 baseline；若接近禁忌門檻，需進腫瘤委員會討論。（2026 指引，第6-7頁）
- **Carcinoid syndrome / VIPoma** 病人治療前應先矯正：
  - 電解質異常
  - 脫水
  - hypoproteinemia（2026 指引，第7頁）
- 要主動找出以下風險：
  - hydronephrosis / 腎流出道阻塞
  - 腸阻塞風險
  - 高肝腫瘤負荷
  - 既往高度骨髓毒性治療史（2026 指引，第6頁）

## 腎保護：177Lu 也不能省略

- 雖然 177Lu 的腎毒性遠低於 90Y，但 **腎保護仍是 mandatory**。（2026 指引，第7頁）
- 標準作法是 co-infuse **L-lysine + L-arginine**：
  - 各 **25 g**
  - 加在 **1-2 L normal saline**
  - **PRRT 前 30-60 分鐘開始**
  - 總輸注時間約 **4-6 小時**。（2026 指引，第7頁）
- 若病人有 **心衰竭 / carcinoid heart disease**，需調整液體量，避免 volume overload。（2026 指引，第7頁）
- 一些專家中心會在 amino acid infusion 後接 **furosemide**，但前提是病人整體容量與腎流出道狀態允許。（2026 指引，第7頁）
- 若病人有 **大腎結石**，強迫利尿可能誘發急性阻塞，須特別小心。（2026 指引，第7頁）
- Amino acid 外滲可造成 bullae 等皮膚併發症，需避免 extravasation；若發生可考慮局部 vasoprotective care。（2026 指引，第7頁）

## 止吐與輸注耐受性準備

- Amino acid infusion 常見 **噁心、嘔吐**，治療前通常要先給 antiemetic。（2026 指引，第7頁）
- 只有 lysine/arginine 的配方，通常比過去全 amino acid 配方更好耐受。（2026 指引，第7頁）
- 可用較溫和的 prophylaxis，例如：
  - 5-HT3 antagonist
  - 視需要加 steroid（2026 指引，第7頁）

## Somatostatin analogue (SSA) 用藥安排

- 病人若正在用 **長效 SSA**，PRRT 通常排在長效針一個 cycle 的尾端，以避免理論上的受體競爭。（2026 指引，第7頁）
- 但 2026 也指出，近年的影像研究顯示 **SSA 不一定會降低腫瘤攝取**，因此重點是排程一致與臨床穩定，而不是機械式停藥。（2026 指引，第7頁）
- **短效 SSA** 一般建議在 PRRT 前 **1 天停用**；但若病人不打短效藥就會失控，則不能硬停。（2026 指引，第7頁）

## 治療前 checklist（建議實務版）

### 醫師 / 核醫師

- [ ] 已確認適應症與病理。
- [ ] 已看過 SST PET/CT，必要時加做 FDG PET/CT。
- [ ] 已確認是否存在 mismatch lesions。
- [ ] 已排除懷孕與嚴重急性共病。
- [ ] 已評估腎功能、骨髓儲備、肝功能與阻塞風險。
- [ ] 高風險個案已進 tumour board。（2026 指引，第6-7頁）

### 護理 / 治療協調

- [ ] 確認病人理解治療流程、可能噁心、疲倦與輸注時間。
- [ ] 確認長效 / 短效 SSA 的排程與最後一次使用時間。
- [ ] 確認病人可接受較長時間輸液與觀察。
- [ ] 對功能性腫瘤病人，先確認症狀是否穩定。（2026 指引，第7頁）

### 腎保護與安全

- [ ] Amino acid 配方、總量、輸液時間已排妥。
- [ ] 有心衰竭或腎結石病史者已先做液體與利尿策略調整。
- [ ] 已提醒避免脫水，必要時先補液。（2026 指引，第7頁）

## 哪些病人治療前要更積極客製化

- **腎功能邊界值**：需先決定是否降低活度、加強 hydration、是否請 nephrourology 先看。（2026 指引，第6、8頁）
- **骨髓儲備下降**：可能需要 hematology input、後續 transfusion / growth factor 策略預想。（2026 指引，第8頁）
- **高肝負荷或肝功能差**：需在一開始就把 activity reduction 與 subacute hepatotoxicity 風險納入。（2026 指引，第6、12頁）
- **功能性腫瘤**：務必先穩定激素相關症狀，否則治療當天較容易發生 hormonal flare/crisis。（2026 指引，第7、11頁）

## 2026 與過去實務相比，準備階段最重要的變化

- 不再只是「看有沒有 SST 攝取」；而是更重視 **SST-PET / FDG-PET / CT-MRI 的整體一致性**。
- 不再把高肝負荷一律視為排除條件，而是改成 **更嚴格的肝風險管理**。
- Dosimetry 雖未全面成為 mandatory，但對 **腎功能差、骨髓差、重治療個案** 已更傾向提早規劃。（2026 指引，第9-11頁）

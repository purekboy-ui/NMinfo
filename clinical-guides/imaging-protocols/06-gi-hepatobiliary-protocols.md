# 胃腸、肝膽與脾臟核醫 protocol

更新日期：2026-05-16

## 1. Gastric emptying scintigraphy

### 最新優先來源

- Consensus Recommendations for Gastric Emptying Scintigraphy  
  <https://tech.snmjournals.org/content/36/1/44>
- 2024 compliance review  
  <https://tech.snmjournals.org/content/52/1/24>

### 技術 baseline

| 項目 | 主流做法 |
| --- | --- |
| 標準餐 | 低脂 egg-white meal 為國際共識主流 |
| 禁食 | 至少 6 小時，常規為隔夜空腹 |
| 停藥 | 影響胃排空藥物通常至少停 48 小時，除非檢查目的就是評估用藥效果 |
| Window / collimator | Tc-99m 140 keV 20% window；LEAP 或 LEHR |
| Matrix | 128 x 128 |
| Acquisition | 0、1、2、4 小時至少各一組 anterior + posterior 1 分鐘影像；雙探頭可同步 |

### 處理重點

- 以前後 geometric mean 降低深度影響
- ROI 要包含整個胃，避免把鄰近小腸誤納入
- 4 小時時間點非常重要，不能常規省略

## 2. Hepatobiliary scintigraphy / HIDA

### 主要來源

- SNM guideline for Hepatobiliary Scintigraphy 4.0  
  <https://snmmi.org/common/Uploaded%20files/Web/Clinical%20Practice/Procedure%20Standards/2010/Hepatobiliary_Scintigraphy_V4.0b.pdf>
- Appropriate Use Criteria for Hepatobiliary Scintigraphy in Abdominal Pain  
  <https://snmmi.org/Web/Web/Clinical-Practice/Appropriate-Use-Criteria/Articles/Appropriate-Use-Criteria-for-Hepatobiliary-Scintigraphy-in-Abdominal-Pain.aspx>

### 技術 baseline

| 項目 | 主流做法 |
| --- | --- |
| Tracer | Tc-99m DISIDA / mebrofenin 等 hepatobiliary agents |
| 病人準備 | 過短與過長禁食都會影響；通常約 4–6 小時較合適 |
| Acquisition | 立即開始 dynamic，常見 1 frame / min 持續至少 60 分鐘 |
| Matrix | 常用 128 x 128 |
| Views | anterior 為主，必要時加 RAO / lateral / SPECT/CT |

### 技術要點

- morphine 或 CCK / sincalide protocol 必須固定執行條件
- 若要算 GBEF，輸注速率與餐刺激方式不能亂改
- 肝功能差、TPN、重病病人會改變表現

## 3. [99mTc]Tc-mebrofenin hepatobiliary scintigraphy SPECT for liver function

### 最新優先來源

- Joint EANM/SNMMI/IHPBA Procedure Guideline for [99mTc]Tc-Mebrofenin Hepatobiliary Scintigraphy SPECT  
  <https://snmmi.org/Web/Clinical-Practice/Procedure-Standards/Standards/Joint-EANM-SNMMI-IHPBA-Procedure-Guideline-for--99mTc-Tc-Mebrofenin-Hepatobiliary-Scintigraphy-SPECT.aspx>

### 技術定位

這不是一般腹痛 HIDA，而是偏肝切除前功能分區評估與術前規劃。未來若網站要做進階版，可獨立成頁。

## 4. Gastrointestinal bleeding scintigraphy

### 主要來源

- Gastrointestinal Bleeding Scintigraphy  
  <https://snmmi.org/Web/Clinical-Practice/Procedure-Standards/Standards/Gastrointestinal%20Bleeding%20Scintigraphy%203_0.aspx>

### 技術 baseline

| 項目 | 主流做法 |
| --- | --- |
| Tracer | Tc-99m labeled RBC |
| Acquisition | 注射後立即 dynamic；先密集 frame，必要時延長至較晚時間點 |
| Matrix | 常用 128 x 128 |
| View | anterior abdomen/pelvis 為主 |

### 技術要點

- 真正陽性要符合：先出現、強度增加、沿腸道移動
- 自由鎝、泌尿系統、子宮、血管、脾臟都可能造成誤判

## 5. Liver-spleen scintigraphy

### 來源

- ACR/SNMMI/SPR Practice Guideline for the Performance of Liver and Spleen Scintigraphy  
  <https://snmmi.org/Web/Web/Clinical-Practice/Procedure-Standards/Standards/ACR-SNMMI-SPR-Practice-Guideline-for-the-Performance-of-Liver-and-Spleen-Scintigraphy.aspx>

### 技術定位

臨床使用量不如過去，但對 reticuloendothelial function、accessory spleen 或特定脾臟問題仍有角色。

## 6. 小腸與大腸 transit

### 來源

- SNMMI/EANM guideline for Small-Bowel and Colon Transit  
  <https://snmmi.org/Web/Clinical-Practice/Procedure-Standards/Standards/Small-Bowel-and-Colon-Transit-1-0.aspx>

### 技術提醒

- 這類功能檢查的價值建立在標準餐、標準時間點與完整追蹤，不適合隨意縮短流程

## GI / 肝膽影像共通陷阱

- 未取得或未對照近期內視鏡、CT/MRI 解剖影像
- 忽略用藥、禁食時長或近期介入對 GI 動態檢查的影響
- 只看單張靜態影像下結論，未回看動態 raw sequence
- 少拍關鍵延遲時間點，無法區分間歇性與持續性異常

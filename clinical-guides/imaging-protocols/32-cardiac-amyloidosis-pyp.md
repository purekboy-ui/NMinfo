## 檢查定位

ATTR cardiac amyloid 影像最重要的不是算一個 ratio，而是先確認心肌攝取是真的在心肌，不是血池殘留。

## Acquisition parameter table

| 欄位 | 主流 baseline |
| --- | --- |
| Detector / modality | planar + SPECT 或 SPECT/CT |
| Tracer | 99mTc-PYP；不同地區亦可用 DPD / HMDP |
| Patient prep | 一般無特殊禁食要求 |
| Uptake time | 常見 1 小時；部分 protocol 會在 3 小時補拍 |
| Position | supine |
| Planar views | anterior 胸部基本 |
| SPECT | 強烈建議加入，用於區分血池與心肌攝取 |
| Matrix | planar / SPECT 常見 128x128 |
| Orbit / arc | cardiac SPECT 常規 arc 或 360° 視系統 |

## Image processing parameter table

| 欄位 | 主流 baseline |
| --- | --- |
| Reconstruction family | iterative reconstruction 常見 |
| Attenuation correction | 視是否有 SPECT/CT |
| Reorientation | cardiac standard planes |
| Quantification | H/CL ratio、視覺分級；但需與 SPECT 結果一起看 |

## QC checklist

- 是否有做 SPECT 或 SPECT/CT
- 血池殘留是否明顯
- 平面 ROI 放置是否標準
- 掃描時間點是否固定在科內採用版本

## Artifact / pitfall checklist

- 只有 planar 沒有 tomographic 確認
- 血池殘留誤判為心肌陽性
- rib uptake / soft tissue overlap

## 科內落地時最該固定的欄位

- 1 小時或 3 小時 protocol 的採用規則
- 是否所有陽性疑問例都加做 SPECT 或 SPECT/CT
- H/CL ratio 的 ROI 放置方式
- planar 與 tomographic 結果不一致時的判讀規則

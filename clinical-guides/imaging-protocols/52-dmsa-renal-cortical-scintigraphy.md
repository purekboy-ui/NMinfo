## 檢查定位

DMSA 是高解析皮質檢查。真正重要的是小器官高解析設定與 motion 控制。

## Acquisition parameter table

| 欄位 | 主流 baseline |
| --- | --- |
| Detector / modality | planar renal cortical imaging，可加 SPECT |
| Tracer | Tc-99m DMSA |
| Patient prep | 補水；減少病人移動 |
| Timing | 注射後 2–4 小時；腎功能差可更晚 |
| Position | supine |
| Collimator | LEHR、LEUHR 或 pinhole |
| Matrix | 128x128 或 256x256 |
| Zoom / pixel size | 目標約 2–4 mm |
| Counts goal | 每 view 至少約 200k 或固定 5–10 分鐘 |
| Views | posterior、雙 posterior oblique，必要時 anterior |

## Image processing parameter table

| 欄位 | 主流 baseline |
| --- | --- |
| Reconstruction family | 若做 SPECT，多為 iterative reconstruction |
| Attenuation correction | 視是否有 SPECT/CT |
| Quantification | differential cortical function、scar / defect pattern |

## QC checklist

- 是否有 motion blur
- 注射是否順利
- 是否出現異常高肝背景
- 視野是否涵蓋異位或旋轉異常腎臟需求

## Artifact / pitfall checklist

- motion blur
- pinhole 幾何不一致
- 肝背景偏高暗示品質問題
- 沒補 appropriate oblique / anterior 導致解剖誤判

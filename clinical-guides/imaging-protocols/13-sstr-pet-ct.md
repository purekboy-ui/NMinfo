## 檢查定位

SSTR PET/CT 是 NET 與 theranostics 重要基礎影像。技術上要同時處理小病灶檢出與大量生理性攝取背景。

## Acquisition parameter table

| 欄位 | 主流 baseline |
| --- | --- |
| Detector / modality | PET/CT |
| Tracer | 68Ga-DOTATATE / DOTATOC / DOTANOC 等 |
| Patient prep | 一般不需嚴格禁食；追蹤時需保持流程一致 |
| Uptake time | 多約 45–90 分鐘區間 |
| Position | supine |
| FOV / scan range | skull base 或 vertex 至 mid-thigh；必要時全身 |
| Time/bed | 多約 2–4 分鐘/bed |
| CT role | 低劑量 CT AC 基本； staging 時可加診斷 CT |

## Image processing parameter table

| 欄位 | 主流 baseline |
| --- | --- |
| Reconstruction family | TOF OSEM 常見 |
| Iterations / subsets | 依 vendor preset |
| Attenuation correction | CT AC |
| Scatter correction | vendor preset |
| Resolution recovery / PSF | 視系統可用 |
| Quantification | SUV 可輔助追蹤，但需同流程比較 |

## QC checklist

- tracer 與等待時間是否記錄完整
- scan range 是否足夠涵蓋已知 / 疑似病灶分布
- CT-PET 是否配準良好
- 是否需要額外局部延長或局部高解析補強

## Artifact / pitfall checklist

- 脾臟、肝、腎上腺、腎臟與尿路生理攝取
- 炎症或非 NET 病灶的受體表現
- 過強 PSF 視覺上放大小病灶

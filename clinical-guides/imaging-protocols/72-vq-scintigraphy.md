## 檢查定位

V/Q 檢查的技術重點是 ventilation 與 perfusion 都要做得像樣，才能談 mismatch。

## Acquisition parameter table

| 欄位 | 主流 baseline |
| --- | --- |
| Detector / modality | planar 多投影；許多中心已做 V/Q SPECT 或 SPECT/CT |
| Perfusion tracer | Tc-99m MAA |
| Ventilation | gas 或 aerosol，依院內設備 |
| Patient prep | 視呼吸狀況與合作度調整 |
| Position | 依 protocol 固定 |
| Views | 標準胸部多投影；若 SPECT 則完整 tomographic acquisition |
| Matrix | planar 常見 128x128 |
| CT role | 若有 SPECT/CT，可加強定位 |

## Image processing parameter table

| 欄位 | 主流 baseline |
| --- | --- |
| Reconstruction family | 若做 SPECT，多為 iterative reconstruction |
| Attenuation correction | 視 SPECT/CT workflow |
| Reorientation | 肺部標準 planes |
| Quantification | 多以分布模式與 mismatch 為主 |

## QC checklist

- ventilation study 品質是否足夠
- aerosol 是否有中央氣道 hot spot
- perfusion 注射是否順利
- 若做 SPECT/CT，是否 misregistration

## Artifact / pitfall checklist

- poor ventilation quality
- aerosol 中央沉積
- 只靠單面投影簡化解讀

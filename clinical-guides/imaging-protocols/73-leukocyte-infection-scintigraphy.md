## 檢查定位

這類檢查的成敗有一半發生在 lab。血液標記、無菌與 QC 做不好，後面影像再漂亮也沒有意義。

## Acquisition parameter table

| 欄位 | 主流 baseline |
| --- | --- |
| Detector / modality | planar serial imaging，可加 SPECT/CT |
| Tracer | In-111 leukocytes 或 Tc-99m HMPAO leukocytes |
| Patient prep | 依感染部位與 clinical question 安排 |
| Labeling | 無菌、可追溯、具 QC |
| Imaging time | 依 tracer 與問題分早期、延遲、必要時更晚 |
| CT role | SPECT/CT 對定位很有幫助 |

## Image processing parameter table

| 欄位 | 主流 baseline |
| --- | --- |
| Reconstruction family | 若做 SPECT，多為 iterative reconstruction |
| Attenuation correction | 視 SPECT/CT workflow |
| Quantification | 多以序列變化與分布模式為主 |

## QC checklist

- blood handling 與 labeling QC 是否完成
- 各時間點是否符合該 tracer protocol
- 是否需要與 bone marrow imaging 對照
- raw serial images 是否完整保留

## Artifact / pitfall checklist

- 標記品質不穩
- 時間點選錯
- 生理性骨髓 / 脾臟 / 腸道分布誤判
- 忽略 lab 端可追溯紀錄

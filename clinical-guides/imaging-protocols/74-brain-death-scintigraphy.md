## 檢查定位

這不是一般神經灌流檢查的延伸版，而是高度程序化、與重症醫療流程緊密配合的確認性檢查。

## Acquisition parameter table

| 欄位 | 主流 baseline |
| --- | --- |
| Detector / modality | planar dynamic，必要時加 static |
| Tracer | 99mTc perfusion agents，依 guideline |
| Patient prep | 與重症團隊確認生命支持條件與轉運安全 |
| Position | supine |
| View | anterior 為主，需完整涵蓋頭顱 |
| Matrix | 常見 128x128 |
| Dynamic framing | 注射當下即刻動態 |
| Delayed static | 依 protocol 補充 |

## Image processing parameter table

| 欄位 | 主流 baseline |
| --- | --- |
| Reconstruction family | 多以 planar dynamic / static 為主 |
| Quantification | 以灌流有無與典型表現為主，不靠複雜定量 |

## QC checklist

- 注射是否確實進入血管
- dynamic 是否完整從 bolus 開始
- 視野是否完整
- 與重症/神經團隊的程序文件是否一致

## Artifact / pitfall checklist

- 注射外漏
- dynamic 起始太晚
- 視野裁切
- 將技術不完整影像過度解讀

## 科內落地時最該固定的欄位

- 與重症 / 神經團隊的啟動流程
- dynamic 起拍規則
- 視野與標準投影要求
- 技術不完整時是否重做或如何註記

## 檢查定位

這類 transit 檢查的價值完全建立在標準化時序。  
如果影像時間點亂掉，幾乎就失去比較價值。

## Acquisition parameter table

| 欄位 | 主流 baseline |
| --- | --- |
| Detector / modality | planar serial imaging |
| Tracer | 依 protocol 為口服或餐標記 tracer |
| Patient prep | 依 GI motility protocol 控制飲食與藥物 |
| Position | 站立或 supine，需一致 |
| View | anterior abdomen 為主 |
| Matrix | 128x128 常見 |
| Imaging schedule | 依 protocol 設定多時間點，必須固定執行 |

## Image processing parameter table

| 欄位 | 主流 baseline |
| --- | --- |
| Quantification | 幾何中心、segmental transit 或其他 protocol-defined 指標 |
| ROI | 腸段 ROI 需一致且依 protocol 定義 |

## QC checklist

- 標準餐或口服 tracer 是否完整給入
- 各時間點是否準時
- 中間是否有其他活動影響 transit

## Artifact / pitfall checklist

- 漏拍晚期時間點
- 藥物未停
- 不同姿勢或不同時間基準混用

## 科內落地時最該固定的欄位

- 標準餐或口服 tracer 方式
- 各時間點排程
- posture 是否固定
- transit 指標與 ROI 算法

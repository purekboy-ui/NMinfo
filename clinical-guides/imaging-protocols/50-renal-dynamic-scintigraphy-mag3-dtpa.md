## 檢查定位

這是標準時序功能檢查，注射 bolus 品質、排尿、hydration 與 frame timing 會直接決定 renogram 的可信度。

## Acquisition parameter table

| 欄位 | 主流 baseline |
| --- | --- |
| Detector / modality | dynamic planar renal scan |
| Tracer | MAG3 或 DTPA |
| Patient prep | 補水；開始前先排尿 |
| Position | posterior 為主；移植腎 / 異位腎用 anterior |
| Collimator | LEHR 或 general-purpose |
| Matrix | 64x64 或 128x128 |
| Perfusion phase | 1–2 秒/frame，1–2 分鐘 |
| Functional phase | 10–15 秒/frame，約 5 分鐘 |
| Excretion phase | 20–30 秒/frame，至總長 20–30 分鐘 |
| Post-void image | 建議加做 |

## Image processing parameter table

| 欄位 | 主流 baseline |
| --- | --- |
| Reconstruction family | 不適用，主要為 dynamic planar |
| Quantification | differential function、Tmax、drainage pattern 等 |
| ROI | 腎臟與 background ROI 需固定邏輯 |

## QC checklist

- 注射是否像 bolus、是否有 extravasation
- 病人是否先排尿
- raw cine 是否完整
- ROI 是否避開肝脾 / 腸道重疊

## Artifact / pitfall checklist

- hydration 不足
- bladder 充滿未排
- extravasation
- 只看數值不看原始影像

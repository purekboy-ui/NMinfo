## 檢查定位

HIDA 是動態功能檢查，禁食狀態、opioid 影響、動態時序與藥理輔助條件都必須標準化。

## Acquisition parameter table

| 欄位 | 主流 baseline |
| --- | --- |
| Detector / modality | dynamic planar，可加 SPECT/CT |
| Tracer | Tc-99m mebrofenin / DISIDA 類 |
| Patient prep | 常以 4–6 小時禁食為宜；需記錄 opioids、TPN、肝功能狀態 |
| Position | supine |
| View | anterior 基本，必要時 oblique / lateral |
| Matrix | 128x128 常見 |
| Dynamic framing | 注射後立即開始；常見 1 frame / min，至少 60 分鐘 |
| CT role | SPECT/CT 於特定定位問題有幫助 |

## Image processing parameter table

| 欄位 | 主流 baseline |
| --- | --- |
| Quantification | 若做 GBEF，需固定刺激方式與演算法 |
| ROI | 肝、膽囊、小腸等 ROI 視 protocol 需要 |

## QC checklist

- 禁食時間是否在合理範圍
- opioids 或其他干擾因素是否記錄
- dynamic 是否完整保留
- 若做 CCK / sincalide / morphine，給藥條件是否標準化

## Artifact / pitfall checklist

- 禁食過短或過長
- opioid 干擾
- 肝功能異常導致延遲卻誤判
- GBEF protocol 混用

## 檢查定位

現代 parathyroid 影像的主流不是單靠 planar，而是 planar 與 SPECT/CT 的定位整合。

## Acquisition parameter table

| 欄位 | 主流 baseline |
| --- | --- |
| Detector / modality | planar + SPECT/CT |
| Tracer | Tc-99m sestamibi 為主 |
| Technique | dual-phase 或 dual-isotope subtraction |
| Position | 頭頸固定穩定 |
| Planar matrix | 128x128 常見 |
| SPECT matrix | 128x128 常見 |
| Orbit / arc | 360° |
| Time/view | 約 20–30 秒/stop 常見 |
| CT role | 低劑量 CT localization |

## Image processing parameter table

| 欄位 | 主流 baseline |
| --- | --- |
| Reconstruction family | iterative reconstruction 常見 |
| Attenuation correction | SPECT/CT 時可用 CT AC |
| Reorientation | 頭頸標準 planes 與對位 |
| Quantification | 以視覺定位為主 |

## QC checklist

- 前後時相或雙核種影像是否對位
- 頭頸是否有 motion
- 是否涵蓋頸部至上縱膈
- 是否需要 SPECT/CT 補定位

## Artifact / pitfall checklist

- 甲狀腺結節干擾
- motion 造成假性殘留 / 消失
- 只看 planar 忽略 tomographic localization

## 檢查定位

GI bleeding scan 的重點是動態出血模式，不是單張腹部亮點。

## Acquisition parameter table

| 欄位 | 主流 baseline |
| --- | --- |
| Detector / modality | dynamic planar serial imaging |
| Tracer | Tc-99m labeled autologous RBC |
| Patient prep | 依急重症情境安排，重點是盡快開始標準化收像 |
| Position | supine |
| View | anterior abdomen / pelvis 基本 |
| Matrix | 128x128 常見 |
| Start | 注射後立即動態收像 |
| Delayed imaging | 必要時延伸至較晚時間點 |

## Image processing parameter table

| 欄位 | 主流 baseline |
| --- | --- |
| Quantification | 以動態模式辨識為主 |
| Review | 必看 raw dynamic sequence，不可只看靜態截圖 |

## QC checklist

- RBC 標記流程是否完成
- dynamic 是否從注射後立即開始
- 是否完整保留足夠時間序列
- 疑似陽性灶是否符合移動模式

## Artifact / pitfall checklist

- 泌尿系統活性
- free pertechnetate
- 血管 / 子宮 / 脾臟等固定結構
- 只有靜態影像無法確認腸道移動

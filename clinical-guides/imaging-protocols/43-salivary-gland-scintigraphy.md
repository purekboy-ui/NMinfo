## 檢查定位

唾液腺掃描是功能檢查，重點在動態變化與刺激後排出，不是單張靜態圖。

## Acquisition parameter table

| 欄位 | 主流 baseline |
| --- | --- |
| Detector / modality | planar dynamic |
| Tracer | Tc-99m pertechnetate |
| Patient prep | 避免影響唾液分泌的因素；刺激物準備一致 |
| Position | supine 或 seated，頭頸固定 |
| View | anterior 頭頸 |
| Matrix | 128x128 常見 |
| Dynamic framing | 依科內 protocol 固定短 frame 連續收像 |
| Stimulation | 檸檬汁或其他刺激方式，時間點需固定 |

## Image processing parameter table

| 欄位 | 主流 baseline |
| --- | --- |
| Reconstruction family | 不適用，主要為 dynamic planar |
| Quantification | time-activity curves、攝取與排出指標 |
| ROI | parotid、submandibular、background 需固定 |

## QC checklist

- 刺激時間點是否記錄
- 動態過程是否有病人移動
- ROI 是否一致

## Artifact / pitfall checklist

- 頭頸 motion
- 刺激時間點不一致
- 只看單張影像不看 curve

## 科內落地時最該固定的欄位

- 刺激物種類
- 刺激時間點
- dynamic frame 長度
- ROI 與 curve 分析方法

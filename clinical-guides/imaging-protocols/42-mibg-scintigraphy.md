## 檢查定位

MIBG 影像是典型「藥物與 collimator 都不能亂」的檢查。  
主要用於 pheochromocytoma、paraganglioma、neuroblastoma 等神經內分泌腫瘤。

## Acquisition parameter table

| 欄位 | 主流 baseline |
| --- | --- |
| Detector / modality | whole-body planar，可加 SPECT/CT |
| Tracer | 123I-MIBG 診斷最常用；特定情況可見 131I-MIBG |
| Patient prep | thyroid blockade；停用干擾藥物；必要時補充用藥清單 |
| Uptake time | 常見 24 小時影像；必要時延至 48 小時 |
| Position | whole-body anterior / posterior |
| Collimator | 123I 建議 MEGP；131I 需高能量對應 collimator |
| Energy window | 依核種設定；123I 常以 159 keV 為主 |
| Matrix | whole-body 依系統固定； spot / SPECT 通常 128x128 常見 |
| CT role | SPECT/CT 用於病灶定位與解剖配對 |

## Image processing parameter table

| 欄位 | 主流 baseline |
| --- | --- |
| Reconstruction family | 若加 SPECT，多用 iterative reconstruction |
| Attenuation correction | SPECT/CT 時可做 CT AC |
| Scatter correction | 依系統與核種條件 |
| Quantification | 多為視覺與半定量輔助，不同中心方法差異大 |

## QC checklist

- thyroid blockade 是否完成
- 干擾藥物是否停用或至少完整記錄
- collimator 是否與核種匹配
- whole-body 掃描範圍是否完整
- 是否需要延遲影像或 SPECT/CT 補定位

## Artifact / pitfall checklist

- 用錯 collimator
- 生理性唾液腺、肝臟、膀胱與腸道分布
- 藥物干擾導致假陰性
- 只做 whole-body 不做局部 tomographic 補強

## 科內落地時最該固定的欄位

- thyroid blockade 流程
- 干擾藥物停用清單
- 24 小時與 48 小時影像的使用條件
- whole-body 後何時加做局部 SPECT/CT

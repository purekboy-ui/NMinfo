# 內分泌與相關小器官核醫 protocol

更新日期：2026-05-16

## 1. Thyroid uptake 與 thyroid scintigraphy

### 最新優先來源

- EANM/SNMMI guideline for Radio-Iodine Uptake and Thyroid Scintigraphy v3.0  
  <https://snmmi.org/Web/Clinical-Practice/Procedure-Standards/Standards/EANM%20SNMMI%20guideline-for-Radio-Iodine-Uptake--RAIU--and-Scintigraphy--V-3-0.aspx>

### 技術 baseline

| 項目 | 主流做法 |
| --- | --- |
| Tracer | Tc-99m pertechnetate、I-123、特定情境 I-131 |
| Collimator | Tc-99m 多用 LEHR；I-123 常用 MEGP 或依系統規範 |
| Matrix | 常見 128 x 128 或 256 x 256 |
| Zoom | 使 thyroid 充滿 FOV 的主要部分，避免太小 |
| Views | anterior 為基本；必要時 RAO / LAO，pinhole 常用於細節 |
| Counts / time | 以足夠 gland detail 為原則，常見 100k–300k counts 或固定數分鐘 |
| RAIU | 必須有標準源、背景與時間點校正 |

### 技術要點

- thyroid scan 很吃 positioning 與 chin extension
- 若做 pinhole，應固定幾何條件與 detector-to-neck 距離
- uptake test 的準確性依賴標準源與時間紀錄，不只是拍到就算

### 常見陷阱

- 碘造影、含碘藥物、amiodarone、甲狀腺藥物干擾
- 下巴遮擋、neck motion
- 胃食道或口腔污染誤認為異常灶

## 2. Parathyroid scintigraphy

### 最新優先來源

- SNMMI guideline for Parathyroid Scintigraphy 4.0  
  <https://snmmi.org/Web/Clinical-Practice/Procedure-Standards/Standards/Parathyroid-Scintigraphy-4-0.aspx>

### 技術 baseline

| 項目 | 主流做法 |
| --- | --- |
| Tracer | Tc-99m sestamibi 為主 |
| 方法 | dual-phase 或 dual-isotope subtraction |
| Planar | anterior neck / upper mediastinum 基本 |
| SPECT/CT | 現代流程多建議加入，提升定位 |
| Matrix | planar 常 128 x 128；SPECT 多 128 x 128 |
| SPECT arc | 360 度常見 |
| Time/view | 約 20–30 秒/stop，視系統與體型調整 |

### 技術要點

- 現代主流已不是只靠早期與延遲 planar，SPECT/CT 很重要
- 病人頭頸固定要好，尤其 dual-phase 比較最怕位置改變
- 若用 subtraction 技術，兩種影像的配準品質是關鍵

## 3. MIBG

### 技術定位

MIBG 雖然量不大，但仍是神經內分泌與某些兒科腫瘤的重要檢查。

### 技術 baseline

| 項目 | 主流做法 |
| --- | --- |
| Tracer | I-123 MIBG 為診斷主流 |
| Collimator | 建議 MEGP，避免 septal penetration |
| Window | 159 keV 為主，依系統可加 scatter window |
| Timing | 常見 24 小時，必要時 48 小時延遲 |
| Whole-body | anterior / posterior 全身基本 |
| SPECT/CT | 針對可疑病灶加做 |

### 技術要點

- 需注意 thyroid blockade 與干擾藥物停用
- I-123 若誤用 LEHR，影像品質與定量都可能受影響
- mediastinal background 與肝臟攝取要熟悉

## 4. Salivary gland scintigraphy

### 技術定位

常見於 Sjogren 或放療後功能評估，屬 GI scintigraphy 家族但實務上常放在頭頸功能檢查。

### 技術 baseline

- Tc-99m pertechnetate
- dynamic acquisition 為主
- stimulation 前後時序要固定
- ROI 放置與 time-activity curve 處理要一致

## 小器官影像通則

- 盡量讓目標器官填滿 FOV，而不是用大視野拍一個很小的器官
- pinhole 或高解析設定若使用，就要把幾何條件固定
- 這類檢查常不是 counts 最大就最好，穩定姿勢與正確定位更重要

# 神經、肺部與感染核醫 protocol

更新日期：2026-05-16

## 1. Brain perfusion SPECT

### 主要來源

- Brain Perfusion SPECT Using 99mTc Radiopharmaceuticals 3.0  
  <https://snmmi.org/Web/Web/Clinical-Practice/Procedure-Standards/Standards/Brain-Perfusion-Single-Photon-Emission-Computed-Tomography--SPECT--Using-99mTc-Radiopharmaceuticals-.aspx>

### 技術 baseline

| 項目 | 主流做法 |
| --- | --- |
| Tracer | Tc-99m HMPAO 或 ECD |
| 注射環境 | 安靜、低刺激、固定姿勢 |
| Position | supine，頭部置中固定 |
| Radius | 盡量小 |
| Matrix | 常用 128 x 128 |
| Pixel size | 約 3–4 mm 等級較理想 |
| Orbit | 360 度 |
| Step | 約 3 度/step 常見 |
| Time/stop | 多依系統與 counts 調整，整體掃描約 20–30 分鐘 |

### 技術要點

- 注射那一刻的環境條件很重要，不能注射完還一直和病人聊天
- raw projection、sinogram、motion review 一定要看
- 後處理需固定 reorientation 與 smoothing

## 2. DaT SPECT / dopaminergic imaging

### 最新優先來源

- EANM/SNMMI guideline for Dopaminergic Imaging in Parkinsonian Syndromes  
  <https://snmmi.org/Web/Clinical-Practice/Procedure-Standards/Standards/Dopaminergic-Imaging-in-Parkinsonian-Syndromes.aspx>
- SNM Practice Guideline for Dopamine Transporter Imaging  
  <https://snmmi.org/common/Uploaded%20files/Web/Clinical%20Practice/Procedure%20Standards/2011/123I_ioflupane_SPECT_Practice_Guideline_JNM_Edit_FINAL.pdf>

### 技術 baseline

| 項目 | 主流做法 |
| --- | --- |
| Tracer | I-123 ioflupane |
| Thyroid blockade | 常規需做 |
| Timing | 注射後約 3–6 小時收像 |
| Collimator | 建議 MEGP |
| Energy window | 159 keV ± 10% |
| Matrix | 128 x 128 |
| Pixel size | 約 3.5–4.5 mm |
| Orbit | 360 度 |
| Angle step | 約 3 度 |
| Time/stop | 常見 30–40 秒/stop |
| Minimum counts | guideline 摘要常提約 1.5 million total counts |

### 處理重點

- iterative reconstruction 優先
- minor motion 可嘗試 correction，但明顯 motion 應考慮重掃
- striatal slice thickness 與 reorientation 需固定

## 4. V/Q 或 pulmonary scintigraphy

### 主要來源

- Pulmonary Scintigraphy archived guideline  
  <https://snmmi.org/common/Uploaded%20files/Web/Clinical%20Practice/Procedure%20Standards/2009/Pulmonary_Scintigraphy_1382732040599_8.pdf>
- Appropriate Use Criteria for V/Q Imaging in Pulmonary Embolism  
  <https://snmmi.org/Web/Clinical-Practice/Appropriate-Use-Criteria/Articles/Appropriate-Use-Criteria-for-Ventilation-Perfusion--V-Q--Imaging-in-Pulmonary-Embolism.aspx>

### 技術 baseline

| 項目 | 主流做法 |
| --- | --- |
| Perfusion | Tc-99m MAA |
| Ventilation | aerosol 或 gas，依院內設備 |
| Planar | 多投影或至少標準胸部投影 |
| SPECT/CT | 現代中心越來越常用 V/Q SPECT 或 SPECT/CT |

### 技術要點

- 若做 aerosol ventilation，要注意環境污染控制與中央氣道沉積
- 先做 ventilation 或 perfusion 要依 tracer 與院內流程一致
- 若做 SPECT/CT，配準與病人呼吸配合很重要

## 5. Leukocyte / infection scintigraphy

### 主要來源

- ACR/SNMMI/SPR Practice Guideline for the Performance of Scintigraphy for Inflammation or Infection  
  <https://snmmi.org/Web/Web/Clinical-Practice/Procedure-Standards/Standards/ACR-SNMMI-SPR-Practice-Guideline-for-the-Performance-of-Scintigraphy-for-Inflammation-or-Infection.aspx>
- Society of Nuclear Medicine Procedure Guideline for 111In-Leukocyte Scintigraphy  
  <https://snmmi.org/common/Uploaded%20files/Web/Clinical%20Practice/Procedure%20Standards/2004/Leukocyte_v3.pdf>

### 技術 baseline

| 項目 | 主流做法 |
| --- | --- |
| Tracer | In-111 WBC 或 Tc-99m HMPAO WBC |
| Lab step | 標記流程需無菌、可追溯且有 QC |
| Imaging time | 依 tracer 與臨床問題分早期、延遲、必要時 24 小時 |
| SPECT/CT | 對骨、脊椎、腹腔與 prosthesis localization 很有幫助 |

### 技術要點

- 這類檢查不是只有拍照，前面的 blood handling 與 labeling quality 就已經決定成敗
- 必須分清楚不同 tracer 的正常生理分布與時間演變
- 若要與 bone marrow imaging 對照，時間安排與對位要事先規劃

## 6. FDG PET in infection / inflammation

### 來源

- EANM/SNMMI guideline on FDG Hybrid PET Use in Infection and Inflammation in Adults 2.0, 2024  
  <https://snmmi.org/common/Uploaded%20files/Web/Clinical%20Practice/Procedure%20Standards/2024/EANM%20SNMMI%20Guideline%20FDG%20Infection%20and%20Inflammation_SNMMI%20BOD%20FINAL.pdf>

### 技術定位

雖屬 PET，但在感染與發炎領域有獨特準備差異，例如心內膜炎、血管 graft、裝置感染等，未來可另開進階單元。

## 神經 / 肺 / 感染共通陷阱

- 忽略病人準備環境
- 只看重建，不看 raw data
- 忘記某些檢查是「動態或多時間點」才有判讀價值
- 用錯 collimator，特別是 I-123 類檢查

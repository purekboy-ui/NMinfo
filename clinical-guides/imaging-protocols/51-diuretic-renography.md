## 檢查定位

diuretic renography 的關鍵是用標準化利尿劑時序檢查排空，不能把不同 protocol 混在一起比較。

## Acquisition parameter table

| 欄位 | 主流 baseline |
| --- | --- |
| Detector / modality | dynamic renal scan |
| Tracer | MAG3 最常用 |
| Patient prep | 良好 hydration；評估 bladder 狀態；必要時導尿 |
| Position | 固定、舒適、可重現 |
| Protocol family | F+20、F+0、F-15 等，科內應固定版本 |
| Matrix | 64x64 或 128x128 |
| Dynamic framing | 依 renography 主流程 |
| Post-void image | 強烈建議 |

## Image processing parameter table

| 欄位 | 主流 baseline |
| --- | --- |
| Quantification | drainage pattern、T1/2、relative function 等 |
| ROI | collecting system 與整腎 ROI 需依 protocol 一致 |

## QC checklist

- 利尿劑給藥時間是否完整記錄
- hydration 是否足夠
- bladder 是否造成下尿路干擾
- 使用的是哪一個 protocol family 是否清楚

## Artifact / pitfall checklist

- protocol 混用
- 腎功能太差時 T1/2 過度解讀
- 巨大膀胱或排尿不佳

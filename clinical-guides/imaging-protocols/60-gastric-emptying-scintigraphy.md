## 檢查定位

GES 是高度標準化檢查。標準餐、用藥管理與 4 小時時間點，比 camera 參數本身更重要。

## Acquisition parameter table

| 欄位 | 主流 baseline |
| --- | --- |
| Detector / modality | planar serial imaging |
| Tracer | Tc-99m sulfur colloid 標記固體餐 |
| Patient prep | 空腹至少 6 小時；影響胃排空藥物通常停 48 小時 |
| Standard meal | 低脂 egg-white meal |
| Position | 站立或固定姿勢，科內需一致 |
| Collimator | LEAP 或 LEHR |
| Energy window | 140 keV 20% window |
| Matrix | 128x128 |
| Imaging schedule | 0、1、2、4 小時至少各收 anterior + posterior 1 分鐘 |

## Image processing parameter table

| 欄位 | 主流 baseline |
| --- | --- |
| Quantification | anterior / posterior geometric mean |
| ROI | 胃 ROI 需完整且避開鄰近腸道 |
| Endpoints | 各時間點胃殘留，4 小時尤重要 |

## QC checklist

- 標準餐是否完整吃完
- 影響胃排空藥物是否停用或完整記錄
- 各時間點是否準時
- 是否真的做到 4 小時

## Artifact / pitfall checklist

- 病人沒吃完餐
- 只做到 2 小時
- ROI 把小腸納入
- 忽略藥物影響

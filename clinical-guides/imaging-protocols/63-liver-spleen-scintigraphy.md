## 檢查定位

這是使用量較少但仍有特定價值的 reticuloendothelial system 檢查。  
常見用途包括 accessory spleen、splenosis、肝脾組織分布與某些功能問題。

## Acquisition parameter table

| 欄位 | 主流 baseline |
| --- | --- |
| Detector / modality | planar，可加 SPECT/CT |
| Tracer | 99mTc-sulfur colloid 或依適應症調整 |
| Patient prep | 通常無特殊準備 |
| Position | supine |
| Views | anterior、posterior、oblique；視問題加局部 |
| Matrix | 128x128 常見 |
| Counts / time | 以足夠顯示肝脾輪廓與 focal defect 為原則 |
| CT role | 若做 SPECT/CT，以定位 accessory spleen 或異位脾組織特別有用 |

## Image processing parameter table

| 欄位 | 主流 baseline |
| --- | --- |
| Reconstruction family | 若加 SPECT，多為 iterative reconstruction |
| Attenuation correction | 視是否有 SPECT/CT |
| Quantification | 多以視覺與分布描述為主 |

## QC checklist

- 臨床問題是否真的適合此檢查
- 是否需要 SPECT/CT 補定位
- 視野是否完整包含疑似 accessory spleen 區域

## Artifact / pitfall checklist

- 局部截切
- 腸道、腎臟或其他解剖結構誤認
- 沒有搭配對位影像就過度解讀

## 科內落地時最該固定的欄位

- 何時只做 planar、何時加做 SPECT/CT
- 視野是否固定包含全肝脾或疑問區
- tracer 選擇與適應症分流

## 檢查定位

骨掃描應明確分成 whole-body delayed、spot view、3-phase 與 SPECT/CT。不同臨床問題需要的 acquisition 結構不同。

## Acquisition parameter table

| 欄位 | 主流 baseline |
| --- | --- |
| Detector / modality | planar whole-body，可加 SPECT/CT |
| Tracer | Tc-99m labeled diphosphonates |
| Patient prep | 補水；注射後至 delayed imaging 間鼓勵排尿 |
| Phase 1 | 注射當下 dynamic flow |
| Phase 2 | 注射後立即至 10 分鐘內 blood pool |
| Phase 3 | 注射後 2–4 小時 delayed skeletal images |
| Matrix | blood pool 常見 128x128 或更高 |
| Counts goal | blood pool 約 300k / image 常見；extremity 可較低 |
| CT role | SPECT/CT 用於定位與提升特異性 |

## Image processing parameter table

| 欄位 | 主流 baseline |
| --- | --- |
| Reconstruction family | 若做 SPECT，多為 iterative reconstruction |
| Attenuation correction | SPECT/CT 時可用 CT AC |
| Scatter correction | 視系統可用 |
| Resolution recovery / PSF | 視系統可用 |
| Quantification | 以視覺與解剖配對為主 |

## QC checklist

- 注射是否有 extravasation
- delayed imaging 時間是否足夠
- 尿液污染是否已辨識
- 是否真的需要 SPECT/CT 補定位

## Artifact / pitfall checklist

- 尿液污染
- 退化性變化 vs 骨轉移
- 延遲時間過短造成背景高
- 局部 spot / SPECT 缺乏對位時過度解讀

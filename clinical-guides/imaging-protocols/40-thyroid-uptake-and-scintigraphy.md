## 檢查定位

甲狀腺影像的核心是小器官高解析幾何一致性，特別是 chin position、pinhole 幾何、標準源流程與干擾藥物管理。

## Acquisition parameter table

| 欄位 | 主流 baseline |
| --- | --- |
| Detector / modality | planar small-organ imaging |
| Tracer | Tc-99m pertechnetate、I-123、特定情境 I-131 |
| Patient prep | 確認含碘顯影劑、amiodarone、甲狀腺藥物與其他干擾因素 |
| Position | 頸部伸展、chin up |
| Collimator | Tc-99m 多用 LEHR；I-123 常用 MEGP 或依系統要求 |
| Matrix | 128x128 或 256x256 |
| Zoom / pixel size | 讓 thyroid 充滿主要 FOV |
| Views | anterior 為基本；必要時 oblique；pinhole 常用於細節 |
| Counts goal | 常見約 100k–300k，依細節需求調整 |

## Image processing parameter table

| 欄位 | 主流 baseline |
| --- | --- |
| Reconstruction family | 不適用，主要為 planar |
| Quantification | uptake test 需固定標準源、背景與時間點 |
| ROI | 若做 uptake / 定量，需固定頸部與背景 ROI 幾何 |

## QC checklist

- 是否有近期碘負荷或干擾藥物
- 標準源與時間點是否完整記錄
- 下巴與頸部位置是否理想
- 是否需要 pinhole 補細節

## Artifact / pitfall checklist

- 食道 / 口腔污染
- 下巴遮擋上極
- pinhole 幾何不一致
- uptake 流程只記結果不記時間與標準源條件

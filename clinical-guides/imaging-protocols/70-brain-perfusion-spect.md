## 檢查定位

這個檢查的技術可信度，很大部分決定於注射前後環境與頭部固定。

## Acquisition parameter table

| 欄位 | 主流 baseline |
| --- | --- |
| Detector / modality | brain SPECT |
| Tracer | Tc-99m HMPAO 或 ECD |
| Patient prep | 安靜、昏暗、低刺激；注射前後避免交談與閱讀 |
| Position | supine，頭部置中固定 |
| Matrix | 128x128 常見 |
| Orbit | 360° |
| Step angle | 約 3° 常見 |
| Radius | 盡量小 |
| Duration | 多約 20–30 分鐘，依 counts 與系統 |

## Image processing parameter table

| 欄位 | 主流 baseline |
| --- | --- |
| Reconstruction family | iterative reconstruction 常見 |
| Attenuation correction | 視系統與 workflow |
| Scatter correction | 視系統可用 |
| Reorientation | 標準腦部 planes |
| Quantification | 視需要做半定量分析 |

## QC checklist

- 注射環境是否符合 protocol
- 頭部是否穩定固定
- raw projection / sinogram 是否有 motion
- 重建與 reorientation 是否一致

## Artifact / pitfall checklist

- 注射時病人受到刺激
- 頭動
- 過度平滑

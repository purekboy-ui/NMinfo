# 腎泌尿核醫 protocol

更新日期：2026-05-16

## 腎泌尿影像的技術核心

- 腎臟檢查最重要的是時序，不是只拍到腎臟。
- 注射品質、hydration、排尿、frame timing、ROI 邏輯會直接影響結果。
- 若問題是 obstruction、relative function、cortical scar、reflux，各自該用的 tracer 與 protocol 不同。

## 1. 成人 renal scintigraphy / renography

### 最新優先來源

- SNMMI/EANM Renal Scintigraphy in Adults, 2018  
  <https://snmmi.org/common/Uploaded%20files/Web/Clinical%20Practice/Procedure%20Standards/2018/Renal%20Scintigraphy_Blaufox_0318.pdf>

### 技術 baseline

| 項目 | 主流做法 |
| --- | --- |
| Tracer | MAG3、DTPA、必要時 DMSA |
| Hydration | 掃描前後良好補水 |
| 排尿 | 開始前先排尿 |
| Position | 後位為主；移植腎或異位腎須前位 |
| Matrix | 64 x 64 或 128 x 128 |
| Dynamic framing | 1–2 秒/frame 持續 1–2 分鐘，之後 10–15 秒/frame 約 5 分鐘，再 20–30 秒/frame 至總長 20–30 分鐘 |
| Collimator | LEHR 或 general-purpose，依系統而定 |

### 關鍵細節

- 注射一定要像 bolus，extravasation 會破壞 renogram
- 常規應加 post-void 或 upright post-micturition image
- ROI 畫法與 background ROI 要固定

## 2. Diuretic renography

### 來源

- SNMMI/EANM guideline for Diuretic Renal Scintigraphy in Adults With Suspected Upper Urinary Tract Obstruction  
  <https://snmmi.org/Web/Web/Clinical-Practice/Procedure-Standards/Standards/Diuretic-Renal-Scintigraphy-in-Adults-With-Suspected-Upper-Urinary-Tract-Obstruction-1-0.aspx>

### 技術 baseline

| 項目 | 主流做法 |
| --- | --- |
| Tracer | 多用 MAG3 |
| 利尿劑 | 常用 furosemide |
| Protocol | F+20、F+0、F-15 視臨床情境與院內一致性 |
| Position | 以固定可重複為先，必要時加 upright / post-void |

### 技術要點

- 真正要固定的是科內採用哪一種 diuretic protocol，不要同院混用又互相比
- hydration 不足與 bladder outlet problem 會讓排空看起來比實際更差

## 3. ACE inhibitor renography

### 來源

- 成人 renal scintigraphy guideline 內已有技術摘要

### 技術 baseline

- captopril 口服後約 1 小時或 enalaprilat IV 後 10–20 分鐘進行 tracer 注射
- 血壓監測要確實
- 若做 baseline + ACEI comparison，兩次流程要高度一致

## 4. DMSA renal cortical scintigraphy

### 最新優先來源

- Pediatric [99mTc]Tc-DMSA Renal Cortical Scintigraphy: An Update, 2021  
  <https://snmmi.org/common/Uploaded%20files/Web/Clinical%20Practice/Procedure%20Standards/2021/SNMMI%20EANM%20DMSA%20guideline_final.pdf>
- 成人整合摘要可參考 Renal Scintigraphy in Adults, 2018

### 技術 baseline

| 項目 | 主流做法 |
| --- | --- |
| Timing | 注射後 2–4 小時開始收像；腎功能差可延後 |
| Collimator | LEHR、LEUHR 或 pinhole |
| Matrix | 128 x 128 或 256 x 256 |
| Pixel size | 目標約 2–4 mm |
| Counts | 每 view 至少約 200k counts，或固定 5–10 分鐘 |
| Views | posterior、雙後斜位，必要時 anterior |

### 技術要點

- 這類檢查最怕 motion，病人舒適與固定比硬撐高解析更重要
- 若用 pinhole，要記錄是否所有病人都採同一幾何條件
- planar 與 SPECT/low-dose CT 的應用要分清楚；不是所有情況都要上 SPECT/CT

## 5. Radionuclide cystography

### 技術定位

用於 reflux 評估，尤其兒科常見；未來可另開兒科專卷。

### 技術重點

- filling、voiding、post-void 都要完整記錄
- time stamping 很重要
- 污染與尿管位置問題常是判讀陷阱

## 腎臟影像處理共通原則

- raw dynamic cine 必看
- ROI 需避開肝、脾、腸道與 collecting system 干擾
- differential renal function、Tmax、T1/2 都不能脫離原始影像脈絡單獨解讀
